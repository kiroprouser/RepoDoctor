# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the maintainers privately through the contact method listed on the repository's GitHub page and ask for a secure reporting channel. Include a concise description, affected versions or commits, and steps to reproduce where safe.

The project has no formal service-level agreement. Maintainers will acknowledge reports as they are able and coordinate disclosure with the reporter.

## Scope

Repo Doctor is a browser-only tool that reads public GitHub repository metadata and files. It does not request credentials, write to analyzed repositories, or support private repositories. Please include the affected component and browser or runtime details in a report.
